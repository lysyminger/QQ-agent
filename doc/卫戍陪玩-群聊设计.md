# 卫戍陪玩：群聊参与设计（先设计，暂不开发）

2026-11-10 整理。目标：喵喵在群里像群友一样一起打卫戍——有人喊「卫？」能发房间邀请，别人发邀请能看语境决定要不要进、怎么回，打的过程中偶尔用黑话吐槽一两句，但不刷屏。
**前提是先把打牌能力练上来**（见文末「上线条件」），现在只是设计。

## 一、从群聊记录里看到的（主群 11-07 ～ 11-09 的聊天，约 190 条相关）

### 邀请长这样（游戏里复制出来的口令）

```
[abcd1234efgh56]群友A邀请你加入卫戍协议:规程【标准模拟】
[0abc12def34g56]群友B邀请你加入卫戍协议:规程【终极模拟】
[h78ij90klm12no]群友C邀请你加入卫戍协议:规程【绝境模拟】
```

- 方括号里是 14 位房间口令（小写字母 + 数字），后面是邀请人的游戏昵称和难度（标准 / 险境 / 绝境 / 终极）。
- 同一个房间会反复发好几次（没人来就再发一遍、开了新房间换新口令）；有时有人引用别人的邀请再 @ 一下。
- 还有一种「[卡片消息]」也可能是邀请（记录里只存了「[卡片消息]」，内容没存下来，**待确认**）。

### 打的时候的黑话和吐槽（挑能用的）

- 运营：**升本**、几本（「三回合开始升本」「第一回合升二」「四回合四本压力队友」）、**没对子升本死路一条**、刷了九只拜松、数值盟约顶住、大散打时代（散修）。
- 盟约强弱：乌萨斯还行、叙拉古叠不起来、不屈叠不起来、阿戈尔不要来蹭克总的强度。
- 血量：**进斩杀线**（10 血以下）、还好没进斩杀线、5 滴血刚好五只（漏五只怪）、漏怪道歉书。
- 联机：来多少兜多少（联防接怪）、送队友三块钱（开局给钱的策略）、我以为你们很能打就选了个三块钱。
- Boss：三星打爆 boss、boss 只有一半血、光一减速没人打伤害、二阶段站起来 30 秒过去了、打到四号位。

## 二、功能设计

### 1. 有人喊「卫？」→ 喵喵发邀请

- 触发：群里出现上表「想打 / 要房间」的话（规则先筛，再让大脑按语境确认是不是在喊人打卫戍，而不是在聊别的「卫」）。
- 谁能让它开：沿用现在的规矩——**主人说了才开**；群友喊时，主人开了「允许群友喊喵喵打卫」开关才响应，否则回一句「等主人放我出去玩」。
- 动作：开模拟器 → 卫戍协议 → 联合模拟 → 选难度（语境里有就用，没有默认标准）→ 建房 → 点邀请 / 复制口令 → 从模拟器剪贴板读出口令 → 发到群里，格式和群友一样，后面跟一句短的（「码来了，速来」）。
- 待验证：游戏里「邀请」按钮是不是把口令复制到剪贴板、雷电怎么读安卓剪贴板（读不到就退回 OCR 房间界面上的口令）。

### 2. 别人发邀请 → 喵喵看语境决定进不进

- 识别：正则 `\[([0-9a-z]{14})\](.+?)邀请你加入卫戍协议:规程【(.+?)模拟】`。
- 先判断能不能进（程序判，不问大脑）：喵喵空闲（没在打）、主人允许、**难度在它的能力范围内**（见文末）、这个口令没进过、邀请发出后 5 分钟内。
- 再看语境决定怎么回（问大脑，带上邀请前后几条消息）：
  - 对方在催（「还有谁要来」「速来」「111没人来我开了」）→ 回「来了」，直接进。
  - 熟人小队在约、没喊外人 → 先问一句「我能来吗」，有人回「来」再进；没人理就不进。
  - 已经满了 / 说了「我们开了」→ 不进，也不说话。
  - 难度超出能力 → 可以吐槽一句婉拒（「终极我去了就是送三块钱的」），不进。
- 进房：把口令写进模拟器剪贴板后切回游戏（游戏一般会识别口令弹出加入）；不行就进「查找房间」输入口令。**待验证**。

### 3. 打的过程中说话（参与感，但别刷屏）

- 只在这些时刻说，挑一件说一句，口语、短、用上面的黑话：
  - 开局定了路线（「这把玩乌萨斯，没对子我就不升本了」）
  - 合了精锐 / 凑齐 6 人核心盟约
  - 进斩杀线、一回合掉了一大口血（「进斩杀线了，下回合不 D 就寄」）
  - 联机里队友漏怪、自己兜住了（「来多少兜多少」）
  - 领袖轮 / Boss 打得爽或者打不动
  - 结算：通关或者中断（「撑到第 12 回合，漏怪道歉书我先写」）
- 频率：每 3 分钟最多 1 句、一局最多 6 句；群里正在聊别的、没人一起打时只说开局和结算两句；群友正在一起打时可以多回应他们的吐槽。
- 实现上已经有一半：runner 的 `report()` 和规划里的 `say` 字段。要补的是「事件 → 说一句」的触发和频率闸门，以及把黑话表给大脑当风格参考。

## 三、要先补的打牌能力（上线条件）

- **单人**：标准独立模拟至少通关几次（现在规程等级 1 还没通关过，最好撑到第 13 回合）。没过之前只陪聊、不进群友房间。
- **联机（群里基本都打联机）**：现在完全没练过。要补：建房 / 进房 / 准备流程、联机的倒计时、联防阶段、给队友送钱的策略、领袖轮合血。建议先自己开标准联合模拟（单人也能开房？待确认）练。
- **难度闸门**：按战绩放开——标准联合模拟胜率过半才接标准的邀请；险境、绝境、终极先一律婉拒。拖队友后腿比不来更扫兴。

## 四、开发顺序（以后）

1. 邀请识别 + 是否进房的判断（纯文本，可以先做，先只在群里「回话」不真进房）。
2. 游戏里联合模拟的建房 / 复制口令 / 进房（要在模拟器上探路、校准）。
3. 联机对局流程（runner 加联机界面：联防、送钱、合血领袖轮）。
4. 打牌过程中的事件说话 + 频率闸门 + 黑话风格。
5. 主人开关：允许群友喊、允许进的最高难度、每天最多打几局。
