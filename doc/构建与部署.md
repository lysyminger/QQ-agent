# 构建与部署（lysy-mods 分支）

从一台新的 Windows 电脑把这个分支跑起来，到打出安装包。只想用核心机器人的话，看第一、二节就够了；第三节是各个插件自己的准备工作，用哪个装哪个。

---

## 一、环境

| 要什么 | 版本 / 说明 | 必须吗 |
|---|---|---|
| Windows 10 / 11 | 便携 QQ、SnowLuma、雷电模拟器都只在 Windows 上测过 | 必须 |
| Node.js | ≥ 20（本机用 24） | 必须 |
| Git | 拉代码 | 必须 |
| 一个 OpenAI 兼容的模型 API | 官方、中转站、学校网关都行，在设置页填 | 必须（或者用 Codex 大脑） |
| QQ 小号 | 非官方协议有风控风险，别用大号 | 必须 |
| ffmpeg | 放进 PATH。做 GIF、视频抽帧、语音转码、表情包转格式都要 | 建议 |
| Codex CLI | `npm i -g @openai/codex`，再 `codex login`。codex-bridge、kb-autolearn、sticker-auto-collect、ark-garrison 用 | 用到这些插件才要 |
| Python + openai-whisper | `pip install openai-whisper`。听视频、QQ 语音转文字用 | 可选 |
| yt-dlp | 抖音视频下载用 | 可选 |
| 雷电模拟器 9 | 卫戍协议陪玩用 | 可选 |

## 二、把机器人跑起来

```bash
git clone -b lysy-mods https://github.com/lysyminger/QQ-agent.git qq-agent
cd qq-agent
npm install
npm run setup        # 下载 SnowLuma + 固定版本便携 QQ（可重复执行）
npm run setup:check  # 只检查是否就绪
```

`npm run setup` 下载失败时的手动办法、QQ 版本为什么要锁定，见 README 里「安装与使用」之后的几节。

启动有两种：

```bash
npm start            # 桌面端（Electron，托盘常驻）；也可以双击 启动QQ机器人.bat
npm run server       # 不要窗口：浏览器打开 http://127.0.0.1:3210
```

第一次启动后：

1. **SnowLuma 页**点「启动 QQ」，用小号扫码登录。
2. **设置页顶部的体检卡**会列出还缺什么：填模型接口地址和 Key → 点「获取列表」选模型 → 点「测试」看通不通。
3. **白名单**：从 QQ 拉群列表，勾上要让机器人工作的群。
4. **人设**：设置页「人设」里改机器人名字和角色卡，怎么写见 [提示词怎么写.md](提示词怎么写.md)。
5. **主人**：插件页打开 `owner-identity`，`ids` 填你自己的 QQ 号。填了之后你在没加白名单的群里也能叫到它，codex-bridge 的「交给电脑执行」也只听这个号。

所有配置都存在 `data/config.json`（含 API Key），**整个 `data/` 不进版本库**。

## 三、插件各自的准备

插件放在 `plugins/` 下，热加载，不用重启。在控制台「插件」页开关；某个插件没生效时，那一页会写原因（未启用 / 依赖缺失 / 加载失败）。

| 插件 | 要先做什么 |
|---|---|
| codex-bridge | 装好 Codex CLI 并 `codex login`。「Codex 模式的工作方式」选 `brain` 就是让 Codex 当大脑（qq-agent 的档位、插件、工具都保留），「Codex 模型」建议填 `gpt-6.1-sol`（留空跟随 `~/.codex/config.toml`）。控制台「Codex」页能看进程、用量、重启 |
| codex-bridge 的「吃什么」 | 在 `data/codex-bridge/food/amap.json` 写 `{"amapKey": "你的高德 Web 服务 Key"}`，运行 `node scripts/build-campus-guide.mjs`（约 70 次高德调用）。之后只读生成的 `shops.json`。学校坐标是脚本里的 `CENTER`，换学校要改 |
| codex-bridge 的语音梗 | 语音库放 `data/knowledge-base/voices/` |
| ark-garrison | `cd plugins/ark-garrison && npm install`（MaaFramework 的 Node 绑定，约 100 MB，装在插件目录里）。装好雷电 9，插件设置里 `ldDir` 留空会从注册表找。想改用 Claude 订阅：本机 Claude Code 登录好，启动前设 `ARK_BRAIN=claude` |
| ark-garrison 资料 | `knowledge/05`、`06` 由 `node scripts/ark-build-data.mjs` 从公开的 ArknightsGameData 生成，仓库里已经带了生成好的版本，游戏更新后再跑一次 |
| sticker-auto-collect | 依赖 codex-bridge（用 GPT 看图把关、写备注）和 ffmpeg |
| agent-reach | 先自己装好 [Agent Reach](https://github.com/Panniantong/Agent-Reach)，加平台、登录在终端里做 |
| zjsru-failover / zjsru-no-think | 只对浙江树人学院的免费模型网关有用，别的学校 / 渠道直接关掉 |

**没有上传的插件**（别人写的，没许可证）：adaptive-group-style、live-context、repeat-echo、burst-merge、inner-life、life-memory、quote-reply、meme-tracker。仓库里没有它们机器人也能跑，只是少这些功能；`.gitignore` 里已经列了它们，本机放着不会被误提交。

### 卫戍协议陪玩的命令行

```bash
node plugins/ark-garrison/play.mjs indie 1          # 试玩一局独立模拟 · 规程等级 1
node plugins/ark-garrison/train.mjs --mode coop     # 后台训练：联合模拟（随机匹配），一局接一局
node plugins/ark-garrison/sim.mjs --compare         # 不开模拟器，用本地假游戏整局整局地跑
```

训练记录在 `data/ark-garrison/`（`runs/*.jsonl` 每一步、`stats.jsonl` 每局结果、`train.log`）。**联机中途不要杀训练进程**，会被游戏判挂机违规；要停就在控制台「Codex」页点「暂停（打完这局）」，或者建 `data/ark-garrison/PAUSE`。

## 四、测试

```bash
npm test                 # 核心全量（26 套）
npm run test:prompt      # 只测提示词拼接
npm run test:coverage    # 覆盖测试：模块层 + 全部 HTTP 接口 + 端到端 + 界面
```

本分支插件的测试单独跑（都不连 QQ）：

```bash
node test/forward-sticker-test.mjs       # 合并转发、表情包
node test/ark-garrison-test.mjs          # 卫戍陪玩（不连模拟器、不调 Codex）
node test/sticker-auto-collect-test.mjs  # 表情包自动收集
node test/food-pick-test.mjs             # 吃什么（要先生成店单）
node test/agent-reach-test.mjs
node test/workshop-test.mjs              # 工具工坊
```

`test/selftest.mjs` 会加载 `plugins/` 下全部插件，装了 send-pacing 这类延迟发送的插件时会在「等待会话结束」那步超时，和代码改动无关。

## 五、打安装包

```bash
npm run dist             # = electron-builder --win，产物在 dist/
```

- 打出来的是 NSIS 安装包 `QQ-Agent-V0.4-Preview-Setup.exe`，`asar` 关着，装好后插件目录照样能改。
- `data/`、`runtime/`（便携 QQ）、`snowluma/` 的配置和日志、`test/`、`doc/`、`scripts/` 不打进去。便携 QQ 在用户机器上由 `npm run setup` 或首次启动时下载。
- **打包前先看一眼 `plugins/`**：本机放着的别人的插件也会被打进去。要分发给别人就先挪走它们，再跑 `node scripts/sanitize-release.mjs --dry-run` 看还会清掉什么。

## 六、多开 / 换机器

- 同一台电脑跑第二个 QQ 号：`node scripts/setup-second-instance.mjs`，说明见 [extend_development/multi-instance.md](extend_development/multi-instance.md)。
- 搬到新电脑：代码重新 clone；把旧电脑的 `data/` 整个拷过去就带上了配置、记忆、存档和表情库。`data/` 里有 API Key 和聊天记录，别传到网上。
- 分享自己的部署副本前：`node scripts/sanitize-release.mjs`（清空 Key、白名单、存档、登录态）。
