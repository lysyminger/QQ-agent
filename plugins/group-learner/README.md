# group-learner · 群内学习（群文化记忆）

让机器人在群里**不断学习、越来越像真人**，并且**每个人设各记各的**，换人设不用重新拉取历史、不浪费 token。

## 它解决什么

QQ Agent 自带的记忆只记「对某个群友的印象」（他什么性格、爱玩什么梗、雷点），
而且靠模型主动调 `memory_append` 才记 —— 实测模型几乎不主动调，等于长期空转。

缺的是「**这个群整体长什么样**」这层知识：群内黑话、烂梗、常聊话题、群氛围、
人物关系、称呼习惯。这层东西才是"越来越像本群真人"的关键。

本插件补上这层，而且：

| 需求 | 怎么满足 |
| --- | --- |
| 不断学习、越来越像真人 | 每次被触发回复时，后台把近期群聊喂给「记忆整理模型」，批量提炼成「群文化」，攒得越久越像本群人 |
| 每个人设记住群里的东西 | 知识按「人设指纹」分槽存储，和 `archive-isolation` 用同一套指纹、槽位天然对齐 |
| 换人设不重新拉取、不费 token | 换人设 = 指针切到另一份文件，秒切；切回旧人设那份知识原样还在。每次回复只注入约百来字，不重读历史 |

## 怎么工作

1. **学习（后台，自动）**：机器人每次回复时，数一数这轮看到的新消息。攒够
   `minNewMessages` 条、且距上次整理超过 `digestIntervalMinutes` 分钟，就把最近
   `windowMessages` 条群聊喂给模型，合并进当前人设的「群文化」文件。
2. **注入（每次回复，一小段）**：把当前人设的群文化作为【群文化记忆】一小段塞进
   提示词，机器人说话时自然带上（黑话、梗、称呼），不重读历史。
3. **人设隔离**：换人设时只切指针，知识各自独立存在 `data/group-learner/<会话>/<人设槽>.json`。

## 怎么用（无需写代码）

装好后开箱即用，默认对所有群生效。要精调，去控制台「插件」页签找到「群内学习·群文化记忆」：

- **想马上看效果**：把「整理冷却时间」调到 30 分钟、「攒够多少条」调到 3，然后在
  「手动操作」框填群号（如 `1071355009`）保存 —— 它会立刻整理一次，结果写进「上次操作结果」。
- **想省钱**：去「设置 → 记忆」把「记忆整理专用模型」配成一个便宜模型（`useChatModel` 关掉、
  选提供商和模型）。这样学习和官方记忆整理共用同一个便宜模型，不烧主模型 token。
- **只对某个群学**：在「只在这些群学习」填群号。
- **查看/清空**：手动操作框填 `群号:view`（查看）或 `群号:reset`（清空全部人设的群文化）。

> 提示：手动操作和 `archive-isolation` 一样，需要机器人真的回复你一次才会执行
> （最省事的做法是私聊机器人说一句话，然后去控制台看「上次操作结果」）。

## 数据放在哪

```
data/group-learner/
  group_<群号>/
    state.json          # 当前用哪个人设槽位 + 计数
    p_xxxxxxxx.json      # 每个人设一份群文化（黑话/话题/氛围/关系/口头禅）
```

## 常见问题

- **切回旧人设，群文化还在吗？** 在。每个人设一份独立文件，切换只是改指针。
- **会打扰机器人正常聊天吗？** 不会。整理全程在后台跑、不阻塞回复；失败只记日志。
- **和 archive-isolation 冲突吗？** 不冲突，反而互补：它隔离「存档 + 群友印象」，
  本插件隔离「群文化」，三样东西在同一时刻一起切。
