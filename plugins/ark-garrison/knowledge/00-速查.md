# 卫戍协议速查（每一步都带上；细节按画面上出现的名字另外附）

## 规则
- 自走棋 + 全自动塔防。只有休整期能操作：买干员、摆位、戴装备、刷新、升级调度中心；作战全自动，作战中什么都不用点。
- 资金每回合发、回合结束清零，所以每回合把钱花完。出售干员得 1 资金。手动刷新默认 1 资金。
- 调度中心等级 = 能买到的最高阶（玩家叫「几本」）；升级费用每回合自动 -1，最低 0。
- 买到第 3 个同名初始干员自动合成 1 个精锐（特质数值约翻倍），并免费三选一一个高一阶干员，这个三选一一定要拿。
- 场上人数有上限（初始 8，画面右侧「剩余可放置角色」）。只有场上的干员参与作战。
- 漏怪按数量扣目标生命，每回合最多扣 10；10 以下是斩杀线，要优先保命。
- 部署顺序从上到下、再从左到右；干员倒下后原位自动再部署（要费用）。
- 核心盟约（国家）3 人激活，6 个不同干员有强化；附加盟约多数 2 人激活，3 人或达到层数有强化。
- 只有激活的盟约能叠层；叠层时机：获得时（买到瞬间）、战斗中（要上场）、休整期结束 / 进入休整期（一般要上场，写了整备区生效的除外）。
- 远见、奇迹、投资人三个盟约放在整备区也算人数。
- 「身前一格 / 身后一格 / 同一行 / 周围八格」类特质，站位决定收益。
- 领袖轮（最后一回合）不能叠战斗中的层数。

## 运营原则
- 优先级：这回合别漏怪 > 升调度中心 > 凑对子 / 凑盟约人数 > 刷新找牌。
- 早期（1～3 回合）先买能打的地面阻挡 + 一个远程，别让怪漏进来；然后按 3、5、7 回合左右升级，第 7 回合前后到 5 本找核心。
- 看到能凑成 3 个的对子优先买；叠层手优先合精锐。
- 主玩 1 个核心盟约 + 2～3 个附加盟约。当期社区认为乌萨斯、莱塔尼亚最简单最强，阿戈尔最稳，伊比利亚最弱。
- 不绑核心盟约的稳妥思路：精准 + 灵巧（+迅捷），后期再转入一个核心盟约吃加成。
- 通用好牌：温蒂（3 买 3 卖不亏钱、带坚守）、空弦 / 渡桥 / 帕拉斯（给身前干员叠层，站在主力身后）、夏栎 / 星源（放整备区也给最高层盟约叠层）、霍尔海雅、迷迭香、魔王。
- 装备：维式重锤类给主输出；盟约之币、见钱眼开玩偶这类「装备时销毁得资金」的立刻用掉；随身身份牌给主盟约的人（不需要已激活）。
- 精准 3 人让所有远程无视 30% 防御和法抗，前期最稳；坚守 3 人是最便宜的兜底。

## 操作约定（1280x720 坐标，截图上叠了 80 像素的黄色网格和刻度）
- **整备区 = 棋盘下方那条木板走道**。买来的干员站在木板上（头顶有 Ⅰ/Ⅱ… 等阶角标），**站在木板上的不参与作战**。
- **上场必须自己拖**：从木板上的干员身上按住，drag 到棋盘格子中心，dir 给朝向（敌人从哪边来就朝哪边）。拖起来时能放的格子会亮绿色；高台（方框格）放远程，平地格放近战。
- 放成功的标志：右侧「剩余可放置角色」的数字减 1。点「准备就绪」前一定看这个数：还是满的（比如 8）说明一个人都没上场，先拖人。
- 商店展开和收起时镜头会变，木板和棋盘在画面上的位置不一样，所以每次都按当前截图里干员实际站的位置拖。
- 拖到右下角「拖拽至此售出」那块是出售（+1 资金）。
- 「冻结 / 解冻」是锁商店，平时别点；不小心冻上了（按钮显示「解冻」）就再点一下解开。
- 只点你在画面上确实看到的东西；不确定就先 wait 或点空白处看看反应。
- 有倒计时的选择界面（开局选核心盟约组、选策略、机变 / 悬赏）：每一步要十几秒，别一个个点开看详情，直接从画面上看得到名字的选项里挑一个确认；选错也比超时强。
- 商店里点一下卡片是选中，卡片上会出现「确认购买」，再点它才真的买（花的是局内资金）。
- 弹窗、教程对话：找关闭（×）、确认、继续，或点对话框本身推进。
- 绝对不要点任何花源石、充值、购买礼包、寻访 / 招募、改账号设置、退出登录的东西。
- 三选一的选择界面（战术决策、道具补给、机变）：先点选项，再点「确认 / 确认选择」，最后才「收起」。只点选项就收起等于没选，界面会弹回来（2026-11-11 实测连着两次这样白花十几秒）。
- 战术决策挑牌看条件能不能达成：「整备区空时……」这种要木板（整备区）上一个人都不留，我们平时木板留 4 个左右，这类牌基本白拿，优先选无条件的加成。
