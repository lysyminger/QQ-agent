# 高手打法（分阶段决策）

来源：卫戍协议复刻版 sganggs/Stronghold-Protocol 的 docs/AI-STRATEGY.md（第二期「盟约」的 AI 队友打法，规则照官方数据核对），
挑了两期通用的原则改写；加上本地模拟（真实属性和经济参数）里验证过的几条。具体干员 / 盟约以这一期的资料（02、03、06）为准。

## 每回合的思考顺序
1. 先看上回合结果：漏了多少怪、生命还剩多少（10 以下是斩杀线，先保命）。
2. 再看这回合的敌人（右上角能看出怪）：空中怪要有**真能打空中**的输出且射程够；隐匿怪要有反隐，或者有能挡住它、活得下来的人；元素怪要有元素回复（行医分支医疗）；「频次」类要攻击次数多；「折射」看伤害类型。缺什么先补什么。
3. 然后才是凑盟约和合精锐。已经叠起来的层数是投资，**碰到一两个烂商店别放弃主盟约**。

## 分阶段
| 阶段 | 要做的 |
|---|---|
| 第 1～3 回合 | 只看手头便宜的牌，先摆出**能用的阵容**：有能挡的前排（阻挡 ≥2）、有远程、最好有治疗。拿得起的对子就拿。认准一个可能的主盟约 + 一个备选，**别把盟约全开一遍**。别想着买高阶。 |
| 第 4～7 回合 | 冲主盟约的下一个人数门槛（核心 3 人激活、6 人强化），完成有用的三合一。 |
| 第 8～10 回合 | 做精锐、补副盟约，把防空 / 反隐 / 治疗的短板补齐。 |
| 后期（11 回合起，最后一两回合是领袖） | 看领袖是谁、有什么威胁（空中、隐匿、元素、频次），留几个不同的伤害来源；领袖有单次伤害上限，几下中等伤害比一下超大伤害更稳。 |

## 主盟约（路线）
- 一局主打 1 个核心盟约 + 最多 2 个副盟约。副盟约挑和主盟约共用干员多、便宜（Ⅰ～Ⅲ阶）的。
- **换主盟约要有具体理由**（比如连续好几回合商店不出、被领袖克制），换的时候在 memo 写「改路线：原因」。只是增减副盟约不算换路线。
- 联机时看队友在凑什么：卡池是共用的，别和队友抢同一个主盟约的稀缺牌。

## 钱和人
- 钱回合结束清零：能花就花，没想买的就刷新找牌。
- 升级调度中心抢的是买人的钱：前期先保证场上人够、不漏怪；费用降到 2 块以内再升最划算（程序会自动升）。
- 场上满了还有更强的人：按**真实战力**换（攻击、攻速、生命、防御），不是只看阶；场上唯一的挡怪的人别换下去，正在凑的对子别卖。（本地模拟：按真实战力换人比不换多撑 1 回合，按阶换反而更差。）
- 木板堵满了买不进新卡：卖掉不成对、不在路线里的低阶。

## 站位
- 敌人从红门那边来：挡怪的近战（重装、近卫、先锋）站在路上靠前；远程、医疗站后面高台，攻击范围要罩住路。
- 「身前一格 / 身后一格 / 同一行 / 周围八格」类特质，站位直接决定收益。
- 部署顺序从上到下、再从左到右，倒下的人原位再部署要费用。
